# NewAl Cloud

تطبيق Android صغير ومستقل لمحادثة نماذج الذكاء الاصطناعي عبر APIs سحابية متوافقة مع OpenAI، بدون نموذج GGUF محلي.

## الميزات

- واجهة محادثة بسيطة تدعم البث المباشر (SSE) وزر إيقاف.
- مزودون جاهزون: Groq، Google AI Studio (Gemini)، Cerebras، OpenRouter، Mistral، ومزود مخصص.
- حفظ الرابط والنموذج والمفتاح محلياً على الجهاز لكل مزود.
- سجل محادثة متعدد الرسائل مع system prompt مساعد للبرمجة.
- لا توجد مكتبات طرف ثالث للتواصل الشبكي؛ يستخدم التطبيق HttpURLConnection وorg.json.
- لا يستخدم llama.cpp أو C++ أو Termux.

## البناء

يتم البناء تلقائياً عبر GitHub Actions باستخدام Java 17 وGradle 8.7، وينتج APK تجريبي موقّع بمفتاح debug.

من تبويب Actions شغّل Android CI أو ادفع تغييراً إلى main، ثم حمّل artifact باسم NewAl-Cloud-debug.

## الأمان والخصوصية

مفتاح API يُحفظ في SharedPreferences على الجهاز ولا يُرفع إلى هذا المستودع. الطلبات والكود الذي ترسله إلى النموذج يذهبان إلى مزود الـAPI الذي اخترته؛ راجع سياسة الخصوصية وشروط كل مزود.

> أسماء النماذج المجانية تتغير بمرور الوقت، لذلك يمكن تعديل النموذج والرابط من إعدادات التطبيق.
